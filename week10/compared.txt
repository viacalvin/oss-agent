1. 규칙 없이 요청하기 (비교의 기준)
- 문체 — 개조식(~함)인가, 존댓말인가? -> ~이다 체를 사용함
- 만들기 전에 무엇을 할지 먼저 말했나? -> 말안함
- 문서 맨 위에 "작성 / 확인" 줄이 있나? -> 없음
- 어제 정해 온 "내 규칙" 에 해당하는 행동을 했나 -> 안함

2. 지시 파일 쓰고 다시 요청 (고정된 맥락의 효과)
- 문체 — 개조식(~함)인가, 존댓말인가? -> ~임 ~함 체를 사용함
근거 : ~ 박스오피스 정보를 가져오는 도구 모음임
- 만들기 전에 무엇을 할지 먼저 말했나? -> 말함
근거 : week09/tools.py를 먼저 읽고 week10 폴더 상태를 확인함.
- 문서 맨 위에 "작성 / 확인" 줄이 있나? -> 있음
근거 : 작성: Claude Code / 확인: 박지환
- 어제 정해 온 "내 규칙" 에 해당하는 행동을 했나? -> 했음
근거 : ## 요약 ~

3 "고치지 말 것" 을 고쳐 달라고 하기 (권고와 강제), 컨텍스트 채우고 압축하기 (압축 뒤에 남는 것)
- 가. 규칙을 들어 거절하거나 되물음

- 읽은 파일 수 (도구 호출 줄로 셈) -> 5개읽음
- 답의 마지막 줄에 "— 끝" 이 붙었는가 -> 붙음
- 압축하는 데 걸린 시간 (대략) -> 11초
- 화면에 어떤 안내가 나왔는가 -> 했던 대화의 전체요약이 나옴
- CLAUDE.md 의 다섯 규칙을 말하는가 -> 맞음
- 대화로 준 규칙("— 끝")을 말하는가, 실제로 답 끝에 붙었는가 -> 실제로 답끝에 붙고 따로 규칙이라고 말하지 않음
